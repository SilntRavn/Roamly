# 地图路线符号

地图使用路线核验返回的交通分段：公共交通里的步行接驳、地铁、公交分别绘制，不再把所有几何合并成一条同色折线。高德 `buslines` 是同段的备选线路，只绘制所选方案的第一条。

| 方式 | 默认颜色 | 符号 |
| --- | --- | --- |
| 地铁 | 城市对应线路色，未知线路使用紫灰色 | 白色描边实线、空心圆站点 |
| 公交 | 来源提供的专属色，缺失时为琥珀色 | 长虚线、方形站点 |
| 驾车 | 蓝色 | 较宽实线、白色方向箭头 |
| 步行 | 绿色 | 圆点短虚线 |
| 骑行数据 | 青色 | 点划线、方向箭头；仅支持数据展示，现有规划选项未新增骑行 |
| 未核验连接 | 灰色 | 细虚线，标记为景点顺序，不能用作实际道路 |

点击线路或旁边的图标标签可查看方式、线路名、上下车站、该段时间和距离。点击空白、关闭按钮或 Escape 关闭详情。标签沿真实折线长度定位，会避开行程面板、地图控件、景点标记和其他标签；空间不够时隐藏标签，保留线路点击。两种地图共用分段筛选与样式，静态降级用 SVG 实现同样的点击与键盘操作。

## 地铁配色来源与更新

`shared/metro-colors.mjs` 是高德当前[地铁图](https://map.amap.com/subway/index.html)的颜色快照，包含 58 个城市；按城市与完整线路名匹配，避免把不同城市的同号线路混用。来源时间保存在 `metroColorSource`。

更新命令：`node scripts/update-metro-colors.mjs`。脚本使用地铁图自身的 `/service/subway` 数据端点，全部城市读取成功后再写入；不使用已经过时的 `/subway/data` 静态文件，也不把缺失配色当成官方色。

## 兼容与验证

旧行程只有合并后的路线几何时，先显示通用公共交通符号。再次点击“核验路线”会刷新旧公交缓存并保存线路分段。旧驾车和步行数据仍可直接绘制。

- `npm run build`
- `npm test`（包含分段、备选线路、颜色匹配、旧缓存更新、无效几何、核验状态筛选）
- 开发服务器上的 `/artifacts/route-symbols-preview.html`：杭州的真实高德路线样本，覆盖地铁 1 号线、公交 7 路、驾车和步行；加 `?static=1` 验证静态降级。该预览不写入用户行程。
